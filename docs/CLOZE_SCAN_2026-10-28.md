# 随读 0.12.0：扫描完形填空原题

按用户确认的范围，本版保留正文空格与全部选项，继续用于精读；不添加选答案、判分或答案揭晓。

## 使用

1. 在「导入」选择「完形填空」。
2. 点「扫描完形填空 · 拍照」，或选择已有试卷照片 / 截图。
3. 多页题目可继续拍下一页，也可一次选择多张图；先排好页序，必要时旋转图片。每篇仍最多 12 页、压缩后合计 18 MiB。
4. 点击「识别原题 · 保留空格和选项」。这一步会把所选图片发送到用户配置的 DeepSeek 接口，并记录已返回的 API 用量。
5. 核对正文和单独列出的选项。编辑时用 `[[21]]` 表示第 21 题空格；每题选项按 `21. A. …  B. …  C. …  D. …` 录入，标签间用两个空格或换行隔开。
6. 保存或确认逐词解析；解析完成后从书库打开。阅读显示 `__21__`，保持空格，全部选项排列在正文下方；正文与选项的实际英文可点词、选择翻译、加入复习。

拍照委托系统相机，使用 [Android TakePicture](https://developer.android.com/reference/androidx/activity/result/contract/ActivityResultContracts.TakePicture) 与仅映射 `cache/scans/` 的 FileProvider。相机取消或照片复制完成后清理本次临时文件；应用不申请相机或全盘照片权限。

## 数据和正确性

- 新草稿持久化区分「文章」和「完形填空」。普通文章沿用原识别提示和缓存；完形填空单独使用 OCR、逐词语境缓存版本。
- 完形识别返回逐页正文和结构化题号 / 选项。空格题号与选项必须一一对应，不能重号、漏题或缺选项。存在问题时停止并保留原图，不原样自动重试。
- 不识别勾选状态，不生成正确答案；提示中要求忽略手写答案、答案表和解题解析。结构校验不保证 OCR 逐字准确，识别后仍需对照原图。
- 正文中的空格始终保留为 `[[题号]]`。段落和新生成的选段 / 原句译文也必须保留相同编号，不能将空格翻译成推测答案。
- 新分词版本 3 仅用于完形填空；A/B/C/D 结构标签不计词频，选项原文的实际英文计入词频。UTF-16 词位仍相对保存的原文；阅读用等长下划线替换标记，点词位置不发生变化。
- 数据库 v4 → v5 只为草稿增加 `kind`，旧文章、词库、API Key 和复习进度保留。备份导出版本 3，恢复仍兼容版本 1 / 2；新完形题包含在学习备份中，原图与密钥仍不导出。

## 验证

构建、单元测试和 Android 设备检查的最终结果随交付更新。验证使用本地固定题目和模拟 HTTPS 响应，不使用用户的真实 API Key，不发出付费 API 请求；模拟器不能替代用户手机实拍精度与相机兼容性验证。

### 最终验证（2026-10-28）

- 50 项 JVM 单元测试、Android 14 的 59 项与 Android 12 的 58 项适用设备检查全部通过，无失败或忽略项。Android 12 未运行仅支持 API 33+ 的着色器编译检查，该项不计入通过数量。
- 两系统的六条释义关闭 / 返回路径正文像素差值均为 0；现有玻璃光学、普通文章导入、旧数据迁移、复习、查词和备份恢复检查通过。
- 新增 9 项完形核心检查、两系统各 8 项完形导入 / 界面检查，覆盖多页与选项页、缺题 / 重题、保留空格的译文、UTF-16 词位、缓存隔离、相机输出 URI、手动录入、页面重建恢复、选项点词与浅深色界面。
- APK 延续原签名，可覆盖旧版。具体 SHA-256、签名和测试日志在交付目录 `verification/`。
- 本轮真实付费 API 请求为 0；实拍 OCR 精度和用户真机表现仍需实际安装体验。
