# 词境·随读

在 Android 手机上完成图片文章导入、阅读、语境释义、本地词库统计与复习的独立应用。

当前版本：**0.6.0-context-assistant**，应用包名 `com.yy.suidu`。

## 功能

- 多张图片导入，AI 辨别正文与页面杂项，提取文章并生成主题标题；文章按时间区分。
- 点击单词查看本文释义、词性和常见释义；支持长按选词、选句翻译。
- 单词出现频率与复习进度保存在手机 SQLite 数据库中。
- 复习使用较短例句，显示单词释义时同时展示句子中文意思；支持移出复习队列。
- 支持删除文章，并更新相关词频与复习关联。
- 单词详情中可向 DeepSeek 提问，问题携带当前单词及文章语境。
- 透明玻璃、渐变背景与弹簧动效；Android 13 及以上支持 AGSL 折射渲染，Android 12 使用兼容效果。

## API 与缓存

在手机设置中输入自己的 API Key，密钥不会写入源码。图片识别与文字分析涉及网络请求，词库与复习数据保存在本地。

请求尽量保持固定提示词和文章前缀，以适配服务端前缀缓存；同时使用本地结果缓存、分批处理和缺失词定向修复，避免重复提交已完成的内容。实际服务端缓存命中及用量以 API 返回的统计为准。

## 构建

需要 JDK 17、Android SDK 36。用 Android Studio 打开本目录，或运行：

```sh
./gradlew :mobile:testDebugUnitTest :mobile:assembleDebug
```

Windows 使用 `gradlew.bat`。调试 APK 位于 `mobile/build/outputs/apk/debug/mobile-debug.apk`。

最低系统版本为 Android 12（API 31）。本仓库只包含独立随读应用，不依赖旧版应用、私人学习资料或本机工具链。

## 验证

0.6 版本已有 25 项 JVM 测试通过，并完成 Android 14（API 34）与 Android 12（API 31）的设备测试，覆盖阅读位置、弹窗关闭后清晰度、文章删除、复习移除和本地缓存。语境提问等新增网络功能仍需结合实际 API 响应与手机环境验证。

源码自行构建使用本机调试签名；安装包更新是否能覆盖安装取决于签名是否一致。
