# 随读 0.11.0 · 阅读与可靠性升级

包名 com.yy.suidu，versionCode 13，数据库 v4。签名兼容性及最终测试结果以交付目录 verification 为准。

## 数据和逻辑

- 新文章分词支持拉丁字母、重音与组合音标，保留 UTF-16 字符位置。中文不会被当成英文单词。非法词元会给出具体诊断。
- 旧文章以数据库已保存的词位为准；旧草稿保留分词版本和已完成的批次。旧 ASCII 缓存不能覆盖新重音词位。
- 文章列表不再加载正文。草稿总批数落库，刷新串行执行；点词只累计计数，到离开阅读或进入词库时更新统计。
- 评分、移出复习和删除文章使用独立的本地任务，不再等待 AI 长任务。
- 解析最多三路并发；每批独立验证、落盘、保存恢复点。一批失败会取消同组未完成请求，已完成结果保留。
- 网络请求分别持有连接，取消作用于全部未完成连接；不自动重发失败请求。
- OCR 图片读取与 Base64 编码在 IO 线程分块写入请求，不构造整组图片的 Base64 JSON 字符串。
- 图片引用成功更新后清理无引用副本，入库时再清理一次。清理失败不会删除已提交引用的新文件。

## 备份恢复

设置提供 JSON 导出与恢复，支持旧版格式 1 和新版格式 2。新版包含文章、可继续处理的文本草稿、解析批次、词库、复习、用量和文本缓存；不含 API Key、原图和设备路径。

恢复按正文哈希合并文章，重复导入不会重复计词；已有复习进度优先保留。恢复前校验正文位置、词位、卡片义项、编号和引用关系，写入在同一事务中完成，失败回滚。旧版缺少的草稿父记录会重建。新版用量记录有稳定编号防止重复累计。

导入文件大小上限 32 MiB。图片型未识别草稿恢复后需要重新选择图片，也可以手动输入正文。保持手动备份方案，未启用系统云备份。

## 阅读和交互

- 正文改为连续阅读表面。段落编号默认隐藏，可在设置中打开；保留原生长按选择、点词和逐段译文。
- 查词从半屏打开，上拉至大档；弹层保留系统嵌套滚动和返回处理，补充边界回弹与到位触觉。
- 标签、外观选择、开关和评分增加系统触觉，兼容 Android 12；不强制覆盖用户的系统触觉设置。
- 确认弹窗弹簧缩放进入；阅读页跟随预测性返回进度，取消回弹，下层页面轻微视差。
- 列表大标题滚动后以顶部小标题接续；顶部玻璃与边缘渐隐。
- UI 拉丁文字使用离线 Inter 4.1，中文由系统字体回退；阅读仍使用衬线字体。Inter 授权随 APK 保存于 assets/licenses/Inter-OFL.txt。
- 补全绿、橙、靛、青的浅深色；提示改用玻璃胶囊，进度改为细线。
- 删除文章移入“···”和长按菜单，仍需二次确认；时间显示“今天 / 昨天 / 日期”。
- 复习揭晓后自动准备译文可关闭；关闭后由“翻译此句”手动触发，仍优先复用本地结果。

## 真机调节

设置页面连点版本号 5 次，打开玻璃调节。折射宽度、折射强度、底色浓度、触摸高光立即生效并保存至本机，可恢复默认和复制参数。用户真机满意后可提供复制值，用于后续默认值调整。

可选的手机倾斜高光和 FSRS 本轮未引入；固定复习间隔保持兼容。
