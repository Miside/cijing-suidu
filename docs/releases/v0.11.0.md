# 随读 v0.11.0 · 阅读与可靠性升级

可以直接覆盖安装旧版，保留本机文章、词库和复习进度。Android 12 及以上，包名 com.yy.suidu，数据库升级为 v4。

- 阅读改为连续衬线正文，段落编号默认隐藏；查词半屏打开、上拉展开，支持触觉、跟手返回和标题折叠。
