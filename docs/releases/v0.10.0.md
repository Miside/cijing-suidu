# v0.10.0 · iOS Liquid Glass

全应用改用 iOS Liquid Glass 风格，统一悬浮导航、内容层级与浅深色主题。

- 玻璃导航实时采样下方内容，带边缘折射、触摸高光、拖动拉伸和松手回弹；向下滚动收缩，向上滚动恢复。
- 重做封面书库、导入引导、词库、复习、阅读、释义弹层与设置，统一配色、输入框、按钮、分段选择、开关、字号滑块及自适应图标。
- 同时包含此前本地更新的复习揭晓后原句查词、印刷体单词、切卡自动发音、持久识别诊断和手动录入正文。

## 验证

32 项 JVM 核心测试通过。Android 14 / API 34 的 36 项检查与 Android 12 / API 31 的 35 项检查通过，包含完整界面、数据库和光学效果。两系统各六条弹层关闭路径的正文采样 RGB 平均差值均为 0。Android 12 不支持的 AGSL 专用检查已过滤，不计为通过。

本轮没有真实 API 调用；截图使用本地演示文章，未验证用户真机帧率。玻璃效果为 Android Compose / AGSL 独立实现，系统状态栏、键盘、系统导航和字体由 Android 提供。
